Install via wget

# One-liner install (download + shortcut)
wget -qO- https://work-message.onrender.com/install.sh | bash
# Or download & run manually
wget https://work-message.onrender.com/Messenger-x86_64.AppImage
chmod +x Messenger-x86_64.AppImage
./Messenger-x86_64.AppImage

The install script places the AppImage in ~/.local/share/Messenger/ and adds a desktop shortcut to your application menu.
